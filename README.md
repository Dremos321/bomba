# Convite FNaF — RPG

## Como usar

Abra `index.html` no navegador ou publique a pasta inteira no GitHub Pages.

### Áudio

Por direitos autorais, o pacote não inclui uma cópia do áudio do vídeo do YouTube.

Para usar o áudio que você escolheu, coloque o seu arquivo MP3 em:

`assets/audio/thank-you-for-your-patience.mp3`

O site já está configurado para tocar esse arquivo depois que o jogador clicar em **ABRIR CONVITE**.

### Estrutura

- `index.html` — convite inicial
- `ficha.html` — instruções para criação da ficha
- `style.css` — visual e animações
- `script.js` — áudio, botões e carta
- (imagem de convite removida; a primeira tela agora usa apenas a composição tipográfica) — imagem usada como referência visual
- `assets/audio/` — coloque aqui o áudio

## GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos mantendo as pastas.
3. Vá em Settings → Pages.
4. Em Source, escolha a branch `main` e a pasta `/root`.
5. Salve.
6. O GitHub fornecerá o link da página.

## Observação

O áudio precisa ser adicionado por você caso tenha autorização para utilizá-lo.


### Áudios

Coloque estes arquivos em `assets/audio/`:
- `thank-you-for-your-patience.mp3` — convite e instruções.
- `caught-in-a-loop.mp3` — começa ao clicar em “SABER MAIS” e abrir a carta.
